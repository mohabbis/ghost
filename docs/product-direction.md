# Product direction

Ghost is a **cloud AI operator**: teach it a business workflow once; it executes
that workflow across software the company already uses — APIs and browser
automation today, desktop later — with **human approval on sensitive actions**,
**verification of outcomes**, and a **hash-chained audit log**.

```text
Capture → Review → Approve → Execute → Verify → Recover
```

## Promise

> Teach Ghost a workflow once. It runs reliably, pauses when something is
> sensitive, verifies the outcome, and leaves a record of exactly what changed.

## Who pays first

Operations-heavy SMBs where people re-key the same work between tools every week:

- wholesale / distribution order ops
- property management admin
- bookkeeping / month-end document flow
- logistics / recruiting / healthcare-admin back office

Sell **one painful, measurable, reversible workflow** (reporting, reconciliation,
document processing, onboarding). Expand seats after proof.

## Non-goals

- Not a chatbot or “AI coworker” that acts unsupervised
- Not a Zapier/Make clone (connectors without a trust pipeline)
- Not a desktop Organizer utility as the commercial product
- Not vision-first RPA; prefer APIs → browser → desktop → vision last

## Active vs legacy

| Surface | Status |
|---|---|
| `cloud/` SaaS | **Active** — build and sell this |
| Root Rust/Tauri desktop | **Legacy** — retained; not the roadmap |
