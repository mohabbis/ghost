# Audiences (ICP)

## Primary (sell first)

**Ops leads / office managers at 5–150 person businesses** who:

- move the same information between 2+ systems weekly (email, portal, ERP, Excel, CRM)
- already pay for tools, and will pay to remove a recurring headache
- need a human on send/pay/submit — unsupervised agents are a nonstarter
- care that a manager can see *what ran* afterward

Concrete first verticals: wholesale order ops, property-management admin,
bookkeeping document flow, logistics / recruiting back office.

## Buyer vs user

| Role | Care about |
|---|---|
| Buyer (owner / ops lead) | Hours removed, error rate, auditability, time-to-value |
| User (the person who did the clicks) | Easy capture, clear approve UI, fewer exceptions |

## Not the first audience

- Developers looking for an RPA SDK
- Consumers organizing personal folders (legacy Organizer wedge)
- Enterprises needing SSO/SOC2 on day one (earn that later)
- Teams that want a fully autonomous agent with no approval

## Message that lands

> Show Ghost the job once. It runs it across your existing tools, stops for
> anything sensitive, checks the result, and leaves a log.
