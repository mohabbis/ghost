The wedge

The error that hides between two spreadsheets.

A figure copied into the wrong row. A transposed digit. A stale value no one re-checked. Finance catches these by eye, late, after they've already flowed downstream. Ghost automates the transfer and checks its own work — so the exception surfaces at the keystroke, not in the close.

Record the routine once

Capture the exact re-keying or copy-across you do every period. Ghost compresses it into readable steps you review — not opaque mouse coordinates.

Verify every value

On each step Ghost confirms the value it approved actually landed in the field. Observed doesn't match expected? The run halts and shows you the exception.

Approve, audit, undo

Nothing runs until you approve it, every change is logged to a receipt, and undo data is written first — so any run reverses in one click.

                    Inside the desktop app

                    Three views. One trust pipeline.

                    The marketing site is the reference look. The desktop app is where these views are wired — same language, same approve-before-it-acts model.

                    1. Record & Replay

                      Capture a data-entry routine once, review every step and the value it writes, then replay only what you approved — with each value verified as it lands.

                    2. Workflows

                      Save approved routines and run them again period after period, through the same review → approve → verify → receipt → undo path.

                    3. Organizer

                      Keep the outputs tidy: scan a folder, review the proposed moves and renames, approve, audit, undo. No silent delete, no silent overwrite.

                    Everything else stays off the default surface — experimental tools sit behind an explicit build flag.

                    The trust pipeline

                    Every action takes the same path.

                    Record → review → approve → replay → verify → undo. AI may propose. Deterministic code executes only what you approved — and checks the result.

                    1. 1

                      Record

                      Capture the data-entry routine once — or point Ghost at a folder. Explicit and visible, never in the background.

                    2. 2

                      Review

                      Raw input compresses into readable steps and the value each will write. Typed text redacted; secrets dropped.

                    3. 3

                      Approve

                      Deny-by-default: every step, and each value it writes, needs explicit consent at the trust level you set.

                    4. 4

                      Replay

                      Deterministic code runs the approved plan — no silent delete, no overwrite.

                    5. 5

                      Verify

                      Each step confirms the approved value actually landed. A mismatch halts the run and seals the exception into a receipt.

                    6. 6

                      Undo

                      Undo data is written before every change, so one click puts things back.

                    The sharper claim

                    “Approve before it acts” is table stakes. Catching the error isn't.

                    Every serious automation now waits for a human. Ghost's difference is what it checks before it asks: it verifies each value it writes against the one you approved, so a bad transfer stops at the keystroke instead of surfacing in the close.

                    Connect your AI

                    Use Ghost safely from the AI tools you already work with.

                    Claude Desktop and Cursor can drive a saved-routine demo over local stdio: list → preview → approve in Ghost → execute → receipt. The AI proposes; you approve; deterministic code acts on your machine. ChatGPT needs a remote HTTP/connector path that is still experimental, so it is not supported on the stock local build.

                    1. 1

                      Install Ghost

                      Download for macOS or Windows below. No account, no cloud setup. Save one short routine first if you want the full list→receipt demo.

                    2. 2

                      Add Ghost to your client

                      Paste into Claude Desktop's or Cursor's MCP config (Windows: C:\Program Files\Ghost\Ghost.exe):

                      {
  "mcpServers": {
    "ghost": {
      "command": "/Applications/Ghost.app/Contents/MacOS/Ghost",
      "args": ["mcp", "serve"]
    }
  }
}
                    3. 3

                      Pair, then walk the routine flow

                      Enable a pairing code in Settings. From the client: list_routines → preview_routine → request_routine_approval. Approve in Ghost, then execute_approved_routine and read the receipt — nothing runs until you approve locally.

                    Local stdio only (Claude Desktop / Cursor). No listening socket, no relay, no uploads on the stock build. ChatGPT is not supported on stock local stdio today. Step-by-step: docs/claude-ghost-demo.md in the repo.
