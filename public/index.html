                    The trust pipeline

                    Every action takes the same seven steps.

                    AI may propose. Deterministic code executes only what you approved — and writes the receipt.

                    1. 1

                      Record / Select

                      Record a task, or pick a folder. Explicit and visible — never in the background.

                    2. 2

                      Inspect

                      Raw input compresses into readable steps. Typed text redacted; secrets dropped.

                    3. 3

                      Plan

                      Ghost proposes exact changes and flags conflicts. The plan mutates nothing.

                    4. 4

                      Approve

                      Set each folder to automate, ask-first, or never. Deny-by-default: risky actions need explicit consent.

                    5. 5

                      Execute

                      Deterministic code runs the approved plan — no silent delete, no overwrite.

                    6. 6

                      Audit

                      Every change names the rule that fired and whether it was automated or you-approved. Export to CSV or JSON.

                    7. 7

                      Undo

                      Reversible steps record undo data first, so one click puts things back.

                    Why Ghost is different

                    The opposite of an autonomous cloud agent.

                    Cloud AI agents

                    • Read your email, chat, calendar, and files in the cloud
                    • Sign in to your systems and act on their own
                    • Raw model output drives actions
                    • Your data — and your logins — live on their servers
                    • Hard to see exactly what happened

                    G Ghost

                    • Runs on your Mac or PC — nothing uploaded
                    • Acts only on the plan you approved, at the trust level you set
                    • Deterministic code executes, not the model
                    • Local-first storage, no account, no vendor holds your logins
                    • Every change names the rule that fired — audited and reversible

                    “Ghost may suggest anything, but it only does what you approve — inside a boundary you control.”
