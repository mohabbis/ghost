Grant recording permissions

To watch and replay clicks and keystrokes, macOS needs you to allow Ghost under System Settings → Privacy & Security in both Accessibility and Input Monitoring.

Not granted yet

Grant one permission at a time. After you enable Ghost in Settings, click Quit & Reopen — macOS applies Accessibility and Input Monitoring when the app launches. Use the Ghost entry that matches this build (dev vs Applications).

Protect this computer (recommended)

Add a local unlock password so workflows stay encrypted at rest (Argon2id + AES-256-GCM). Nothing is uploaded. You can skip — Organizer still works.

There is no recovery if you forget it — the password never leaves your device.
